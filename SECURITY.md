# Security Policy

Security and user privacy are foundational principles of Blackout Browser. We appreciate responsible disclosure of potential vulnerabilities.

---

## Supported Versions

Only the latest release receives active security patches:

| Version | Supported |
|---|---|
| v0.2.x | Supported |
| < v0.2.0 | End of Life |

---

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through **[GitHub's Private Vulnerability Reporting](https://github.com/justokaywith/blackout-browser/security/advisories/new)** or by emailing **support@pactuno.online**.

* **Do not** disclose vulnerabilities, exploit code, or credentials in public GitHub issues or discussions.
* Please include:
  * A clear description of the issue.
  * Step-by-step reproduction instructions.
  * Affected Windows version and Blackout Browser release.
  * Sanitized evidence / logs (ensure no personal browsing data is exposed).

We aim to acknowledge reports within 48 hours and work with you to verify and patch valid security issues before public disclosure.
