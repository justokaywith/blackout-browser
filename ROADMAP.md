# Blackout Browser Roadmap

This document outlines the direction of Blackout Browser. Priorities evolve based on community feedback, browser engine security updates, and performance optimizations.

---

## Current Release: v0.2.32 (Active & Verified)

- [x] **Native Windows File Associations:** Full registry registration for `.html`, `.htm`, `.pdf`, `.svg`, `.webp`, `.xht`, `.xhtml`, and URL protocols (`http`, `https`).
- [x] **Session Recovery & Tab Stacks:** Tab reordering, double-click close, and <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> persistent session restore.
- [x] **Glassmorphic Music Player:** Frosted glass player with adaptive theme synchronization and verified local offline audio file caching.
- [x] **Web Apps Support:** Modern Chromium Client Hints header emulation for WhatsApp Web compatibility.
- [x] **Enhanced Ad Filtering:** Streamlined ad, popup, and tracker blocking without external extensions.
- [x] **Automated Regression Suite:** 110 automated tests covering renderer, main process, navigation, and URL handling.

---

## Near-Term Priorities

- [ ] **Tab Groups & Workspaces:** Color-coded tab grouping and workspace switching for multi-project workflows.
- [ ] **Enhanced PDF Tools Integration:** Native offline viewing and quick annotations using local Pactuno PDF processing.
- [ ] **Custom Extension Sideloading:** Enhanced permission prompts and verification for unpacked Chrome extensions.
- [ ] **RAM & Process Management:** Automatic suspension of background tabs after configurable idle thresholds.
- [ ] **Export & Import Workflows:** One-click encrypted session and bookmark exports/imports.

---

## Exploring

- [ ] **Cross-Platform Builds:** Experimental macOS (Apple Silicon) and Linux (.AppImage / .deb) desktop packages.
- [ ] **Local AI Sidecar:** Privacy-first offline local LLM assistance for page summarization without sending content to third-party clouds.
- [ ] **Signed Windows SmartScreen Certificates:** Official EV code signing for zero-warning Windows installation.
