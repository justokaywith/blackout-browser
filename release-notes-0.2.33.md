# Blackout0.2.33
Fixes unreadable dark-on-dark content on websites that leave the page canvas transparent. Website tabs and website popups now use the normal white browser canvas instead of inheriting Blackout's dark toolbar background. Pages can still draw their own dark backgrounds; no global CSS recoloring, inversion or forced light theme is injected.
Browser chrome appearance and existing sessions, profiles, cookies, favorites and tabs are preserved. Existing0.2.32 compatibility and playback work remains included. Install/update when ready to restart; running windows are not silently patched.
Verified: runtime page/popup construction regressions and full automated suite. Specific problematic Flippa sections and full native before/after acceptance remain to be checked after updating. This release addresses the confirmed dark backing-canvas bug without claiming to fix every website's own theme CSS.
